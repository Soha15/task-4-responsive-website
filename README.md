# Task 4 - Responsive Website

## Objective
Make a website mobile-friendly using CSS media queries.

## Technologies Used
- HTML
- CSS
- CSS Media Queries
- Chrome DevTools

## Work Done
- Added viewport meta tag
- Added responsive CSS media queries
- Adjusted navigation for mobile screens
- Made content stack vertically
- Adjusted font sizes
- Made the layout fit mobile screens
- Tested the website using Chrome DevTools

## Result
The website is responsive and works on both desktop and mobile screen sizes.
